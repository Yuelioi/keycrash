本次更新精简帮助内容，并调整帮助窗口的滚动布局。

- 普通、专业模式各用三步说明操作，保留 Ctrl+C+C 编排示例，移除历史存储和底层机制等开发说明；中、英、日三语同步。
- 帮助正文按完整内容高度展开，显示纵向滚动条；打开帮助、切换主题或语言时回到顶部。
- 专业模式说明改为“按顺序发送按键，观察软件响应。”，保留应用内快捷键在 3 秒倒计时内切到目标窗口的提示。

本次不改变按键发送和检测逻辑。帮助布局已编译验证，实际画面与滚动尚未完成截图验收。此前 Windows 用户已验证 GoldenDict Ctrl+C+C 与 Print Screen → Snipaste 案例；不代表所有按键和软件都已实测。macOS 专业模式的实际输入、辅助功能权限、响应和界面仍待实机验证。

下载：Windows 10/11（64 位）选择 `windows-x64.zip`，完整解压后运行 `keycrash.exe`；M 系列 Mac 选择 `macos-arm64.zip`，Intel Mac 选择 `macos-x86_64.zip`。

Mac 解压后运行 `KeyCrash.app`，首次定位或专业测试时按提示授予辅助功能权限。Mac 包仅做 ad-hoc 签名，尚未使用 Developer ID 签名或经过 Apple 公证。
