专业模式现可手动编排并测试 `Ctrl+C+C`、多段组合及修饰键双击，普通模式保留原有单组合检测流程。

- 支持点按、按下、松开、等待及步骤排序，最多 32 步、5 秒；准备完成后倒计时 3 秒再发送，原快捷键操作会执行。
- 点“按键选取”后可在本窗口按一个键填入，再自行选择动作并添加，减少从列表找键的操作。
- 最近测试的序列保存在本机，最多两条，可点击载入或单独删除；清空只影响当前编排。
- Windows 提供 146 个按键选项，支持独立小键盘 Enter、媒体、浏览器等按键；macOS 提供 125 个原生按键选项。Fn/Globe 与设备专用控制不包含在内。
- 发送记录和软件响应分别展示；没有响应不代表没有其他监听。Windows 可按需开启“以管理员权限监听”，仅提升监听权限，输入发送仍受系统权限限制。

Windows 已由用户验证 GoldenDict 的 Ctrl+C+C 响应及 Print Screen → Snipaste 案例；并非所有按键和软件均已逐项实测。macOS 专业模式已通过 ARM/Intel 构建和协议检查，实际输入、辅助功能权限、响应及新界面仍待实机验证；目前响应仅覆盖 Carbon 系统热键通知。

下载：Windows 10/11（64 位）选择 `windows-x64.zip`，完整解压后运行 `keycrash.exe`；M 系列 Mac 选择 `macos-arm64.zip`，Intel Mac 选择 `macos-x86_64.zip`。

Mac 解压后运行 `KeyCrash.app`，首次定位或专业测试时按提示授予辅助功能权限。Mac 包仅做 ad-hoc 签名，尚未使用 Developer ID 签名或经过 Apple 公证。普通模式的全局监听检查会短暂暂停所选软件的键盘监听，结束或取消后恢复。
