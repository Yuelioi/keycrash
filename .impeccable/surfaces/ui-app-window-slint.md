# KeyCrash 主窗口

- 模式：Operate。
- 用户任务：单击选择 Ctrl / Alt / Shift，点击开始后只按一个目标键；若组合已占用，再单击一次定位接收该全局热键的软件。
- 主操作：修饰键以可关闭 tags 表示；同一按钮在“开始检测 / 取消 / 定位占用软件 / 再测一次”之间复用，Esc 取消本地等待。
- 必须展示：当前组合、检测状态、明确结论、软件名/路径或未命中边界、简短证据；状态不能仅靠颜色。
- 方向：信号轨迹。借鉴便携式逻辑分析仪的冷灰面板、细测量网格和单条瞬时轨迹，不做深色霓虹仪表盘。
- 记忆点：虚拟修饰键 tags 与本地目标键汇成一条组合读数；本地等待和进程定位时三段短轨迹接入胶囊，结论落定后界面回归安静。
- 约束：单窗口、中文首发、无导航、无全量列表；owner 必须来自匹配 `WM_HOTKEY` 的进程内证据，短时 Hook 完成即卸载，支持 DPI 与键盘操作。
- 未决：正式 logo 与代码签名方案不属于本轮。
