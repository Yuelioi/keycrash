# KeyCrash 主窗口

- 模式：Operate。
- 用户任务：点击一次开始检测，按下一个组合键，立即读懂是否可注册以及结论边界。
- 主操作：同一按钮在“开始检测 / 取消 / 再测一次”之间复用；Esc 始终取消捕获。
- 必须展示：当前组合、检测状态、明确结论、简短解释；状态不能仅靠颜色。
- 方向：信号轨迹。借鉴便携式逻辑分析仪的冷灰面板、细测量网格和单条瞬时轨迹，不做深色霓虹仪表盘。
- 记忆点：按下组合时，三段短轨迹汇入中央按键胶囊；结论落定后轨迹停止，界面回归安静。
- 约束：单窗口、中文首发、无导航、无全量列表、默认不猜测 owner、支持 DPI 与键盘操作。
- 未决：正式 logo 与代码签名方案不属于本轮。
